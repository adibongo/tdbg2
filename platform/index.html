The Shiny edition

The dashboard above is the static edition: it runs in your browser, so it can live on this password-protected site. The Shiny edition runs a live R session behind the page. It can switch between CSV, Excel, Parquet, SQLite, DuckDB and PostgreSQL, re-query the warehouse, draft SQL with AI, and refresh itself when the warehouse is rebuilt. It needs a server, so run it on your laptop or deploy it.

Run it on your laptop

  1. In the RStudio console, paste this one line. It downloads the project, unzips it and opens it as an RStudio project, with the data and the warehouse already built:
    usethis::use_course("https://github.com/adibongo/tdbg2/archive/refs/heads/shiny-lab.zip")
    (First time only: install.packages("usethis"). To clone with Git instead, so you can pull updates: git clone --branch shiny-lab --single-branch https://github.com/adibongo/tdbg2.git tdbg-shiny-lab, then open tdbg-shiny-lab.Rproj. Or download the ZIP and double-click the .Rproj file.)
  2. In the console of that project, run quarto::quarto_serve("02-dashboard.qmd"). The dashboard opens in your browser.
  3. To rebuild every database from the raw files first, render 01-build-data-layer.qmd. It takes about a minute.

Deploy it to the web (Posit Connect Cloud, free tier)

  1. Sign in at connect.posit.cloud with GitHub.
  2. Choose Publish → Shiny, then pick the repository adibongo/tdbg2, branch main, and the primary file platform/lab/02-dashboard.qmd. The manifest.json beside it lists every package.
  3. Optional: add ANTHROPIC_API_KEY under Secrets to switch on the AI SQL assistant.

A Connect Cloud app sits outside this site's password. The course data is synthetic, but if you would rather keep the live app private, choose a private deployment, or run it on a laptop in class.
