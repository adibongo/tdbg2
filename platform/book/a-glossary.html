Appendix A — Glossary

Term Meaning
Accumulating snapshot A fact table with one row per process instance (e.g. a purchase order), updated as it moves through stages
Atomic swap Building a new version in a temporary file and replacing the live one in one step, so readers never see a half-built state
Aggregate technical, commercial and collection (ATC&C) loss Aggregate Technical, Commercial and Collection loss: the share of energy received by a distributor that never becomes cash
Bronze / silver / gold The medallion layers: raw as received; cleaned and conformed; modelled for decisions
Bus matrix A grid of business processes (facts) against shared dimensions, used to plan conformed models
Catalogue The inventory of tables: meaning, owner, lineage, classification and test status
Continuous integration and continuous delivery (CI/CD) Continuous integration and delivery: automatically testing and deploying every change
Conformed dimension One dimension (e.g. dim_depot) shared by every fact that uses it, so totals agree across subject areas
Cosine similarity A measure of how closely two vectors point in the same direction; used to compare embeddings
Common table expression (CTE) Common table expression: a named step in a Structured Query Language (SQL) query (WITH x AS (...))
Data contract An agreement with a source owner on format, schedule, columns and quality
Data steward The person accountable for the meaning and quality rules of a data domain
Debounce Waiting until an input stops changing before reacting to it, which keeps dashboards responsive
Dimension Context for facts: who, what, where, when
Data protection impact assessment (DPIA) Data Protection Impact Assessment: a structured review of privacy risk before high-risk processing
DuckDB An in-process, columnar analytical database; the warehouse engine in this book
Embedding A numeric vector representing the meaning of text (or images)
Fact A measurement of a business event: units, naira, barrels, minutes
Fan-out Rows multiplied by joining to a table whose key is not unique
Freshness How recent the latest data is, relative to when it is needed
Gate The point where tests decide whether new data is published
Grain The precise meaning of one row in a fact table
Hierarchical navigable small world (HNSW) Hierarchical navigable small world: an index for fast approximate nearest-neighbour search over vectors
Idempotent Safe to run more than once with the same result
Lineage The traceable path from a number back to its source records
Masking Hiding part of a value (080******67) for roles that need to recognise, not read
Medallion architecture Organising a warehouse into bronze, silver and gold layers
Nigeria Data Protection Act (NDPA) 2023 The Nigeria Data Protection Act 2023, the principal data protection law in Nigeria
Parquet A columnar, compressed, typed file format for analytics
Periodic snapshot A fact table with one row per entity per period (e.g. depot × stock-keeping unit (SKU) × week)
Pseudonymisation Replacing identifiers with consistent tokens that can’t be reversed without a separately held key
Quarantine Moving rows that fail validity rules into a rejects table instead of deleting or passing them
Retrieval-augmented generation (RAG) Retrieval-augmented generation: grounding an large language model (LLM)’s answer in retrieved documents
Reactive (Shiny) A value that recomputes automatically when its inputs change
Reconciliation Comparing totals between the warehouse and an authoritative external source
Row-level security Restricting which rows a user can see, based on their role or attributes
Slowly changing dimension (SCD) (type 1/2) Slowly changing dimension: overwrite history (1), or keep every version with validity dates (2)
Semantic layer Version-controlled business definitions of metrics and dimensions, compiled to SQL for every consumer
Serving mart A copy of gold tables shaped and placed for a particular audience or tool
Service-level agreement (SLA) Service level agreement: e.g. “refreshed by 07:00 daily”
Sample-ratio mismatch (SRM) Sample-ratio mismatch: an experiment’s arms are not the sizes the design intended, a sign of bias
Target leakage Using information in a model that would not be available at prediction time
Term frequency–inverse document frequency (TF-IDF) Term frequency × inverse document frequency: a simple word-weighting text representation
Window function A SQL calculation across related rows that does not collapse them (running totals, ranks, lags)
