# Turning Data into Business Growth · Labs (R and Python)

Lagos Business School Executive Education · 12–16 October 2026 · Prof. Bongo Adi

Every chart in the Day 2–5 decks can be regenerated from this folder, and every session has a
beginner-friendly lab with a *Your turn* section. All data are synthetic Nigerian business datasets.

## Quick start

1. Install R and RStudio (and Python if you prefer it). See the Setup page on the course website.
2. Unzip this folder and open `tdbg-labs.Rproj` in RStudio. Every script expects to run from this folder.
3. Install packages once: `source("install_packages.R")` in R, or `pip install -r requirements.txt` for Python.
4. Run a lab line by line, for example `sessions/2-3/R/tdbg_2_3_lab.R` or `sessions/2-3/python/tdbg_2_3_lab.py`.

Each `sessions/<session>/` folder has `R/` and `python/` versions of the same scripts:
`*_lab` (the hands-on lab), `*_figures` (regenerates the deck's charts, IDs such as `S3.4-F02`),
`*_practice_paper` (practice papers) and `*_capstone_starter` (5.4). Charts are written to `figures/`.
